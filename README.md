# カラオケ キーナビ

カラオケでよくある「キーが合わない」「何を歌えばいいか迷う」「音程が安定しない」を解決するWebアプリです。
ブラウザだけで動き、サーバーもインストールも不要です。

## 機能

1. **キー診断**
   - マイクで自分の最低音〜最高音を測定（同じ音を約0.3秒キープすると記録）
   - 曲の音域と比べて、ちょうどいいキー（例: +2、-3）を提案
   - 収まらない場合は、はみ出しが最小になるキーを表示
2. **選曲サポート**
   - 曲リスト（曲名・最低音・最高音）を登録
   - 複数人の音域を登録すると、全員が歌いやすい曲とキーをランキング表示
3. **音程練習**
   - 目標の音を声で追いかけ、ずれ（セント）を色でリアルタイム表示
   - 音域に合わせたスケール、または自分で入力したメロディ（例: `C4 D4 E4`）で練習
   - 練習ごとの正確さを記録

## 使い方

マイクを使うため、`localhost` または HTTPS で開く必要があります（ファイルを直接開くと動かないブラウザがあります）。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

GitHub Pages で公開すれば、HTTPS でそのまま使えます。

## テスト

```bash
node tests/test.js
```

音名変換、キー提案、音程検出（合成波形）のテストが走ります。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` | 画面 |
| `js/notes.js` | 音名・周波数の変換、キー提案の計算 |
| `js/pitch.js` | マイク入力と音程検出（YIN方式） |
| `js/app.js` | 3つのタブの動き、データ保存 |

## メモ

- データ（音域・曲リスト・練習記録）は、この端末のブラウザ内（localStorage）にだけ保存されます。音声は外部に送信しません。
- 最初に入っている曲は**架空のサンプル**です。実際の曲の音域は、ご自身で調べて登録してください。
- 音程の検出精度は、マイクや周囲の雑音に左右されます。ヘッドホンを使い、静かな場所で使うのがおすすめです。
